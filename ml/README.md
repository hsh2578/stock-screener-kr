# 52주 신고가 돌파 성공률 예측 모델

머신러닝을 이용하여 52주 신고가 돌파 종목의 추가 상승 확률을 예측하는 프로젝트

## 프로젝트 목표

52주 신고가를 돌파한 종목이 **20거래일 내 10% 추가 상승**할 확률 예측

## 폴더 구조

```
ml/
├── README.md                 # 프로젝트 설명
├── data/                     # 데이터 파일
│   └── training_data.csv     # 학습 데이터 (4,042개 샘플)
├── src/                      # 소스 코드
│   └── collect_training_data.py  # 데이터 수집 스크립트
├── models/                   # 학습된 모델 저장
├── notebooks/                # Jupyter 노트북 (EDA, 실험)
└── .cache/                   # 캐시 데이터 (OHLCV 등)
```

## 데이터 수집 조건

| 항목 | 값 |
|------|-----|
| 기간 | 2022.01 ~ 2025.06 |
| 시총 필터 | 1,000억원 이상 |
| 제외 | 스팩, ETF, ETN, 리츠, 인프라 |
| 중복 돌파 간격 | 최소 20거래일 |

## 피처 (14개)

### A. 돌파 품질 (3개)
| 피처 | 정의 |
|------|------|
| breakout_pct | (종가 - 직전52주고가) / 직전52주고가 |
| volume_surge | 당일거래량 / 50일평균거래량 |
| close_strength | (종가 - 저가) / (고가 - 저가) |

### B. 베이스 품질 (3개)
| 피처 | 정의 |
|------|------|
| base_length | 직전 52주 고가 이후 경과일 |
| volatility_contraction | 최근5일 변동폭 / 20일 변동폭 |
| volume_dry_up | 최근10일 평균거래량 / 50일 평균거래량 |

### C. 추세 상태 (2개)
| 피처 | 정의 |
|------|------|
| ma200_slope | (200MA - 200MA[20일전]) / 200MA[20일전] |
| pct_above_52w_low | (종가 - 52주저가) / 52주저가 |

### D. 상대강도 (2개)
| 피처 | 정의 |
|------|------|
| rs_vs_market | 종목 20일 수익률 - 시장 20일 수익률 |
| market_return | 코스피/코스닥 20일 수익률 |

### E. 리스크 (2개)
| 피처 | 정의 |
|------|------|
| ma20_deviation | 종가 / 20일선 - 1 |
| liquidity | 5일 평균 거래대금 |

### F. 저항선/변동성 (2개)
| 피처 | 정의 |
|------|------|
| days_since_ath | 역사적 신고가 이후 경과일 |
| atr_ratio | ATR(14) / 종가 |

## 라벨

| 컬럼 | 정의 |
|------|------|
| label | 20거래일 내 최대수익률 ≥ 10% → 1, else 0 |
| max_gain_20d | 20거래일 내 최대 수익률 (%) |
| max_drawdown_20d | 20거래일 내 최대 하락률 (%) |
| gain_at_day_20 | 정확히 20일 후 수익률 (%) |
