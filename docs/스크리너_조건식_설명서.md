# 국내 주식 스크리너 - 조건식 및 로직 설명서

## 개요

- 분석 대상: KRX(한국거래소) 상장 **시가총액 1,000억 원 이상** 약 1,500개 종목
- 데이터: 일봉 OHLCV (FinanceDataReader 기반), 재무 데이터 (FnGuide 크롤링)
- 업데이트: 평일 12:00 / 14:00 / 16:00 / 18:00 KST 자동 실행
- 총 20개 스크리너 (기술적 12 + 가치 2 + 퀀트 2 + 대가 4), 8개 카테고리

## 1. 박스권 패턴 (4개)

### 1-1. 박스권 횡보

60거래일(약 3개월) 이상 좁은 범위에서 횡보 중인 종목. 돌파 전 관심 목록 용도.

**필수 조건 (6가지 모두 충족)**

| 조건 | 기준 | 설명 |
|------|------|------|
| 시가총액 | 1,000억 이상 | 소형주 제외 |
| 횡보 기간 | 60거래일 이상 | 최근 60일 기준 |
| 변동폭 | 박스 범위 <= ATR(60일) x 6 AND <= 25% | 박스 범위가 충분히 좁아야 함 |
| 저항선 터치 | 2회 이상 | 박스 상단 ±2% (고정), 5거래일+ 간격 |
| 추세 없음 | 기울기 절대값 <= 0.05%/일 | OLS 선형회귀 기울기 (횡보 확인) |
| 거래량 감소 | 후반 30일 < 전반 30일 x 0.95 | 관심 이탈 = 세력 매집 가능성 |

- 저점 지지터치(ATR×1.5 범위)는 **필수 조건 아님** — 결과 테이블에 참고 데이터로만 표시
- ATR = Average True Range (평균 진폭). TR = max(고가-저가, |고가-전일종가|, |저가-전일종가|)의 60일 단순평균
- 정렬: 변동폭이 좁은 순 (타이트한 박스권 우선)

---

### 1-2. 박스권 돌파 (거래량)

박스권 상단을 **거래량 동반**하며 돌파한 종목. 거래량 확인이 있어 신뢰도가 높음.

**조건**

| 조건 | 기준 | 설명 |
|------|------|------|
| 박스권 | 위 6가지 조건 충족 | 먼저 박스권 횡보 종목이어야 함 |
| 돌파 | 종가 > 박스 상단 x 1.015 | 상단 +1.5% 초과해야 돌파 인정 |
| 거래량 | 돌파일 거래량 >= 20일 평균 x 2배 | 거래량이 터져야 진짜 돌파 |
| 이평선 | 종가 > 150일선 | 장기 추세 상승 확인 |
| 경과 기간 | 10거래일 이내 | 돌파 후 10일까지만 표시 |

**AI 예측 (ML 모델)**
- 성공확률: 20거래일 내 10% 이상 상승 확률 (XGBoost 분류)
- 예상수익: 20거래일 내 최고 수익률 (Ridge 회귀)
- AI점수 = 성공확률 x 0.7 + 예상수익점수 x 0.3

---

### 1-3. 박스권 돌파 (단순)

박스권 상단 돌파 종목. 거래량/이평선 조건 없이 **돌파 자체**만 판단.

**조건**

| 조건 | 기준 |
|------|------|
| 박스권 | 60거래일 횡보 6조건 충족 |
| 돌파 | 종가 > 박스 상단 x 1.015 |
| 경과 기간 | 10거래일 이내 |

- 거래량, 이평선 조건 없음 -> 더 많은 종목 포착 (거래량 돌파보다 넓은 범위)
- 동일한 ML 모델 적용

---

### 1-4. 풀백

돌파 후 저항선으로 되돌아온 종목. **2차 매수 기회**.

**조건**

| 조건 | 기준 | 설명 |
|------|------|------|
| 선행 | 박스권 돌파(거래량) 발생 | 먼저 거래량 동반 돌파가 있어야 함 |
| 풀백 위치 | 저항선 ±5% 이내 | 돌파 후 되돌림이 저항선 부근까지 |
| 거래량 감소 | 최근 구간 평균 < 돌파일 x 50% | 되돌림 시 거래량 줄어야 건전한 조정 |
| 이평선 | 종가 > 150일선 | 장기 추세 유지 확인 |

- 풀백 탐색 기간: 돌파 후 20거래일 이내
- 정렬: 저항선에 가까운 순

## 2. 거래량 분석 (2개)

### 2-1. 거래량 폭발

당일 거래량이 폭발적으로 증가하며 급등한 종목. **당일 포착용**.

**조건**

| 조건 | 기준 |
|------|------|
| 거래량 | 당일 거래량 >= 40일 평균 x **2.5배** |
| 주가 상승 | 당일 등락률 >= **+12%** (장대양봉) |

- 거래량 비교 기준: 당일 제외 과거 40일 평균
- 정렬: 거래량 배수 높은 순

---

### 2-2. 거래량 급감

급등 후 거래량이 고갈된 눌림목 종목. **세력 보유 매물 소화** 구간.

**1단계: 급등봉 조건 (5가지 모두 충족)**

| 조건 | 기준 | 설명 |
|------|------|------|
| 양봉 | 종가 > 전일종가 x 1.08 | 8% 이상 상승 |
| 거래량 | 20일 평균 x 4배 이상 | 거래량 터짐 |
| 윗꼬리 | (고가-종가)/(고가-저가) < 30% | 매도 압력 적음 |
| 이평선 위 | 종가 > 20일선 | 단기 추세 확인 |
| 갭다운 제외 | 시가 >= 전일종가 x 0.97 | 갭다운 -3% 이상 제외 |

**2단계: 눌림목 조건 (급등 후 3~8거래일)**

| 조건 | 기준 | 설명 |
|------|------|------|
| 가격 유지 | 현재가 > 급등봉 시가 x 0.98 | 급등 전 가격 이상 유지 |
| 조정폭 | 현재가 > 급등봉 고가 x 0.90 | 고점 대비 -10% 이내 |
| 이평선 | 현재가 > 20일선 | 추세 유지 |
| 거래량 고갈 | 최근 3일 평균 < 급등일 x 40% | **60% 이상 감소** |

- 포착 후 8거래일간 표시 유지

## 3. 추세 및 신고가 (3개)

### 3-1. 52주 신고가

52주(250거래일) 신고가를 돌파한 종목. **강세 추세 확인**.

**조건**

| 조건 | 기준 |
|------|------|
| 시가총액 | 1,000억 이상 |
| 52주 고가 | 과거 250거래일 중 고가(High) 기준 최고값 |
| 돌파 | 종가 > 52주 고가 |
| 거래량 | 돌파일 거래량 >= 20일 평균 x **1.5배** |
| 이평선 | 종가 > 150일선 |
| 추세 | 150일선 현재 > 150일선(20일 전) (우상향) |
| 경과 | 8거래일 이내 |

**AI 예측 (14개 피처)**
- 돌파강도, 거래량, 종가강도, 횡보기간, 변동성수축, 거래량고갈, 200일선기울기, 52주저점대비, 시장대비강도, 시장수익률, 20일선이격도, 유동성, ATH이후경과일, ATR비율
- 예상수익: 20거래일 내 최고 수익률
- 성공확률: 20거래일 내 10%+ 상승 확률

---

### 3-2. 52주 신고가 근접

52주 신고가에 **근접했지만 아직 돌파하지 않은** 종목. **돌파 전 매수 타이밍**.

**조건**

| 조건 | 기준 |
|------|------|
| 시가총액 | 1,000억 이상 |
| 괴리율 | 종가가 52주 고가의 **5% 이내** (미돌파) |
| 저항선 확립 | 52주 고가 기록 후 **20거래일 이상** 경과 |
| 경과 | 8거래일 이내 근접 진입 |

**상태 추적**
- `active`: 현재 5% 이내 근접 중
- `breakout`: 이후 52주 고가 돌파
- `dropped`: 5% 이내에서 이탈

**AI 예측 (13개 피처, Lasso + LogisticRegression)**
- 괴리율, 저항선테스트횟수, 고가이후경과일, 5일모멘텀, 거래량비율, 거래량추세, 변동성수축, ATR비율, 이평선정렬, 추세강도, 시장대비강도, 시장수익률, 52주저점대비
- 돌파확률: 10거래일 내 52주 고가 돌파 확률
- 예상수익: 20거래일 내 최고 수익률
- AI점수 = 돌파확률 x 0.7 + 예상수익점수 x 0.3
- 웹에서 기본 3% 필터 적용 (5%로 전환 가능)

---

### 3-3. 이평선 수렴

이동평균선이 좁은 범위로 수렴하며 정배열을 유지하는 종목. **큰 움직임 직전 신호**.

**조건 (7가지 모두 충족)**

| 조건 | 기준 | 설명 |
|------|------|------|
| 거래량 | 10만주 이상 | 유동성 확보 |
| 신고가 | 100주봉 내 최고가가 30주봉 이내 발생 | 상승 추세 확인 (주봉 기준) |
| 정배열 | 10주선 > 20주선 > 60주선 | 단기 > 중기 > 장기 |
| 이격도 1 | 20일선 vs 60일선 <= **5%** | 수렴 확인 |
| 이격도 2 | 20일선 vs 120일선 <= **5%** | 수렴 확인 |
| 이격도 3 | 60일선 vs 120일선 <= **5%** | 수렴 확인 |
| 현재 위치 | 종가 vs 20일선 <= **5%** | 이평선 근처 |

- 이격도 = |A - B| / B x 100
- 이평선이 모여있을수록 에너지 축적, 큰 방향성 이동 가능

## 4. 반등 및 저점매수 (2개)

### 4-1. 바닥 탈출

크게 하락 후 바닥을 다지고 상승 전환하는 종목. **점수제 (12점 만점)**.

**1단계: 필수 조건 (3개 모두 충족)**

| 조건 | 기준 |
|------|------|
| 낙폭 | 52주 고점 대비 **-30% ~ -75%** |
| 신저가 미갱신 | 최근 10일간 52주 신저가 없음 |
| 거래대금 | 5일 평균 거래대금 **1억 이상** |

**2단계: 탈출 신호 (6개 항목, 6점 이상 통과)**

| 항목 | 배점 | 조건 |
|------|------|------|
| 150일선 근접 | 2점 | 종가가 150일선 대비 -5% ~ +15% |
| 150일선 돌파 | 3점 | 아래에서 위로 돌파 + 거래량 1.5배 + 양봉 (5일 내) |
| 저점 상승 | 2점 | 최근 20일 저점 > 이전 20일 저점 (Higher Low) |
| 기울기 상승 | 2점 | 150일선 20일 기울기 > 0 (바닥 탈출 확인) |
| 거래량 급증 | 2점 | 5일 평균 > 20일 평균 x 1.5 |
| MACD 골든크로스 | 1점 | MACD선이 Signal선 상향 돌파 (5일 내) |

**등급**
- A급: 9점 이상 (강력 신호)
- B급: 6~8점 (유력 신호)
- 10거래일 내 6점 이상 달성한 종목 모두 표시

---

### 4-2. 낙폭과대 반등

52주 고가 대비 40% 이상 폭락했으나 **바닥이 높아지는** 종목.

**조건**

| 조건 | 기준 | 설명 |
|------|------|------|
| 낙폭 | 현재가 < 52주 고가 x 0.60 | **40% 이상 하락** |
| 바닥 상승 | 최근 20일 저점 > 이전 20일 저점 | Higher Low 형성 |

- 바닥 상승률 = (최근저점 - 이전저점) / 이전저점 x 100
- 정렬: 낙폭이 큰 순
- PER/PBR 함께 표시 (재무 건전성 참고)

## 5. 가치 및 우량주 (2개)

### 5-1. 저평가 우량주

TTM(최근 4분기 합산) 기반 가치투자 종목. **토요일 주 1회** 업데이트.

**조건 (모두 충족)**

| 조건 | 기준 |
|------|------|
| PER | 업종 평균 이하 |
| PBR | 업종 평균 이하 |
| 매출 성장률 (3년) | 기준 이상 |
| 영업이익률 (평균) | 기준 이상 |
| 영업이익 성장률 (가용 기간) | 기준 이상 |
| EPS 성장률 (가용 기간) | 기준 이상 |

- 재무 데이터 출처: FnGuide 크롤링
- TTM: 가장 최근 4분기 실적 합산 (연환산)

---

### 5-2. 60주선 우량주

60주선(300일 지수이동평균) 위에서 지지받는 수익성 좋은 종목. **평일 18시에만** 업데이트.

**대상**: 코스피 시가총액 상위 200종목

**조건 (4가지 모두 충족)**

| 조건 | 기준 | 설명 |
|------|------|------|
| 이격도 | 0% ~ 10% | 60주선 바로 위에 위치 |
| 이평선 | 종가 >= 60주 EMA | 60주선 위 (이중 확인) |
| 영업이익률 | >= **10%** | 수익성 우수 (최근 결산) |
| 영업이익 성장 | >= **10%** (3년 평균) | 성장성 확인 |

- 60주선 = 300일 지수이동평균(EMA)
- 이격도 = (현재가 - 60주선) / 60주선 x 100

## 6. 퀀트 전략 (2개)

### 6-1. 마법공식

조엘 그린블라트의 마법공식. 이익수익률(Earnings Yield)과 투하자본수익률(ROC)을 합산 순위로 저평가 + 고수익 기업 발굴.

**조건**

| 항목 | 계산식 |
|------|--------|
| 이익수익률 | EBIT(TTM) / EV |
| 투하자본수익률 | EBIT(TTM) / Invested Capital |
| 최종 순위 | 이익수익률 순위 + ROC 순위 (합산 오름차순) |

- EV = 시총 + 총부채(유동+비유동) - 여유자금
- IC = 자본총계 + 차입금 - 현금 (4분기 평균)
- EBIT = 영업이익 (한국 회계 기준)
- 금융주 제외, 시총 1000억+, 보통주만
- 상위 20개 종목 출력
- 데이터: FnGuide 캐시

---

### 6-2. 멀티팩터

Quality + Value + Momentum 3팩터 복합 순위. 섹터 중립화 Z-Score 기반.

**팩터 구성**

| 팩터 | 지표 | 비중(기본) |
|------|------|-----------|
| Quality | ROE, GPA(매출총이익/총자산), CFO/총자산 | 40% |
| Value | PER, PBR, PSR, PCR, 배당수익률 (역수) | 40% |
| Momentum | 12개월 수익률, K-Ratio | 20% |

**처리 과정**
1. Winsorize (상하위 1%) → 원본은 `_orig` 컬럼에 보존
2. 섹터별 Z-Score 정규화
3. Rank → Z-Score → 팩터별 가중합
4. Q/V/M 비중 조절 가능 (프론트엔드 UI)

**필터링**
- 유효 지표 최소 5/10개
- 팩터그룹별 1개 이상 필수
- 금융주 제외 안 함

## 8. 업종 분석 (1개)

### 8-1. 업종별 4단계

네이버 증권 45개 업종을 **와인스테인 4단계** 이론으로 분류.

**4단계 분류 기준** (150일선 기준)

| 단계 | 조건 | 의미 |
|------|------|------|
| 1단계 (바닥) | 가격 < 150일선, 기울기 상승 전환 | 바닥 형성 |
| 2단계 (상승) | 가격 > 150일선, 기울기 > 0 | **매수 구간** |
| 3단계 (천장) | 가격 > 150일선, 기울기 하락 전환 | 천장 형성 |
| 4단계 (하락) | 가격 < 150일선, 기울기 < 0 | **매도/관망 구간** |

- 기울기: 150일선의 최근 20일 변화율
- 기울기 임계값: ±1.0%
